# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the project.

## Format

Each ADR follows the template:

```
ADR-NNNN-short-title.md
```

Copy [ADR-TEMPLATE.md](ADR-TEMPLATE.md), assign the next sequential number, and fill every section. Accepted ADRs may only be reversed by a new ADR that explains which assumptions changed.
